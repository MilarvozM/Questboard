# 委托板 Questboard

像游戏任务日志一样运作的待办清单。你的待办事项就是任务：有步骤、有截止时间、有评级，完成后获得经验值并升级。底层的每个任务都是一个普通的 Markdown 文件，可以用任何文本编辑器或 Obsidian 阅读和编辑，在手机上也可以。

> **状态：第一版。** 下面的步骤都可以使用。中文界面和提示词还在等待母语者审阅。

## 开始使用

你需要两样东西：**Node.js**（运行委托板的免费程序）和**委托板文件夹**。两者都只需要准备一次。

### 1. 安装 Node.js

打开 [nodejs.org](https://nodejs.org/)，下载 **LTS** 版本，按默认选项运行安装程序。

### 2. 下载委托板

在本 GitHub 页面点击绿色的 **Code** 按钮 → **Download ZIP**。解压到一个你找得到的地方，比如“文档”文件夹。

### 3. 在委托板文件夹中打开终端

终端是一个输入命令的窗口。下面的步骤不会更改你电脑的任何设置。

- **Windows：** 打开委托板文件夹，在文件夹内的空白处点右键，选择 **在终端中打开**。
- **macOS：** 打开 **终端** 应用（按 `Cmd+空格`，输入 `终端` 或 `Terminal`，按回车）。输入 `cd` 和一个空格，把委托板文件夹拖到终端窗口里，再按回车。这样终端就进入了该文件夹。

### 4. 启动委托板

把下面这一行粘贴到终端里，然后按回车：

```bash
node questboard.js
```

**这行命令做了什么：** 它让 Node.js 运行这个文件夹里的 `questboard.js` 文件，在你自己的电脑上启动委托板，不会安装任何东西。随后浏览器会打开 <http://localhost:4747>，显示委托板。你的任务不会离开你的电脑。页面唯一从互联网获取的是字体（来自 Google Fonts）；没有网络时会使用电脑上已有的字体。

**停止：** 点一下终端窗口，按 `Ctrl+C`，或者直接关闭窗口。你的任务已经保存好了。

**下次使用：** 重复第 3 步和第 4 步。

## 使用方法

- **快速添加：** 按 `N`，输入标题，按回车。加上 `#home` 指定公会，加上 `@11-02 18:00` 指定截止时间。
- **追踪一个任务**，让它的当前步骤一直显示在屏幕顶部；再给最多 **5 个任务加星标**，作为你的重点清单。
- 每完成一步，点 **完成 / 失败 / 放弃**。所有操作都可以用 `Ctrl+Z`（Mac 上是 `Cmd+Z`）撤销。
- **日历：** 可以切换为只看任务、任务加步骤，或包括已完成内容在内的全部。
- **点击等级徽章**，查看今天、本周、本月和今年完成了多少任务。
- **来自 AI：** 委托板可以为你生成一段提示词。把它和你的笔记一起粘贴到任意 AI 对话中，再把回答粘贴回来，委托板就会把它变成任务。委托板本身从不连接任何 AI。

界面提供 English 和简体中文。

## 你的数据

```
data/
  quests/         进行中的任务，每个任务一个 .md 文件
  completed/      已完成和已放弃的任务
  player.json     按日统计的数据（只有数字）
  history.jsonl   任务完成与重新打开的记录
  guilds.json     你的公会
  settings.json   设置界面中的选择
```

- 每个任务都是可读的 Markdown 文件。可以手动编辑，即使委托板正在运行也没问题，它会自动读取改动。
- 备份方法：复制 `data` 文件夹、同步它，或者用 git 管理。
- 你的 `data` 文件夹永远不会成为本仓库的一部分。

### 配合 Obsidian 使用

把委托板指向你的库（vault）里的一个文件夹（见下方的 `dataDir`）。委托板只读取开头带有 `questboard:` 一行的 Markdown 文件，其他笔记、图片和附件一律不碰。你可以在 Obsidian 中重命名任务文件、把它们放进子文件夹、勾选复选框、把任务标记为完成，在电脑和手机上都可以；委托板下次运行时会全部读取。

手写任务文件的最简形式：

```markdown
---
questboard: 1
title: 更新护照
deadline: 2026-11-20
---

## 目标
- [ ] 拍证件照
- [ ] 去区役所提交
```

## 高级用户的设置

委托板中所有与数字有关的设置——端口、数据文件夹、经验值、评级规则、星标上限、撤销步数、快捷键——都附带注释列在 `config.default.jsonc` 中。

要修改设置，在它旁边新建 `config.jsonc`，只写入你想改的项。例如，把任务放在 Obsidian 库里并换一个端口：

```jsonc
{
  // 任务、已完成任务和玩家数据的存放位置
  "dataDir": "C:/Users/me/Obsidian/Vault/Quests",
  "port": 5050
}
```

`config.jsonc` 属于你自己：更新不会覆盖它，git 也会忽略它。委托板无法使用的值会回退为默认值，终端会告诉你哪一项写错了。

风格在 `styles/`，界面文字在 `locales/`，AI 提示词在 `prompts/`。
