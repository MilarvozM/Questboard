# 委托板 Questboard

像游戏任务日志一样运作的待办清单。

- 你的待办事项就是任务：有步骤、有截止时间、有评级，完成后获得经验值并升级。
- 每个任务都是一个普通的 Markdown 文件，可以用任何文本编辑器或 Obsidian 阅读和编辑，在手机上也可以。
- 委托板只在你自己的电脑上运行，你的任务不会离开你的电脑。
- 界面提供 English 和简体中文。中文文字还在等待母语者审阅。

## 一次性安装

1. **安装 Node.js**，运行委托板的免费程序：打开 [nodejs.org](https://nodejs.org/)，下载 **LTS** 版本，按默认选项运行安装程序。
2. **下载委托板：** 在本 GitHub 页面点击绿色的 **Code** 按钮 → **Download ZIP**。解压到一个你找得到的地方，比如“文档”文件夹。
3. **复制文件夹里 `questboard.js` 的路径**，保存在笔记里：
   - **Windows：** 在 `questboard.js` 上点右键，选择 **复制文件地址**（Windows 10 上需要按住 Shift 再点右键，选择 **复制为路径**）。在笔记里先写 `node ` 和一个空格，再粘贴，得到类似 `node "C:\Users\you\Documents\Questboard-main\questboard.js"` 的一行。
   - **macOS：** 打开 **终端** 应用（按 `Cmd+空格`，输入 `终端` 或 `Terminal`，按回车）。输入 `node ` 和一个空格，然后把 `questboard.js` 从访达拖到终端窗口里。把窗口里出现的这一行，比如 `node /Users/you/Documents/Questboard-main/questboard.js`，复制到笔记里。

以后更新时，下载新的 ZIP，解压覆盖旧文件夹即可。你的任务和设置都会保留。

## 运行

打开任意终端（Windows：开始菜单中的 **终端**；macOS：**终端** 应用），粘贴笔记里的那一行，然后按回车：

```bash
node "C:\Users\you\Documents\Questboard-main\questboard.js"
```

**这行命令做了什么：** 它让 Node.js 运行 `questboard.js` 文件，在你自己的电脑上启动委托板，不会安装任何东西。随后浏览器会打开 <http://localhost:4747>，显示委托板。页面唯一从互联网获取的是字体（来自 Google Fonts）；没有网络时会使用电脑上已有的字体。

**停止：** 点一下终端窗口，按 `Ctrl+C`，或者直接关闭窗口。你的任务已经保存好了。

**先随便看看：** 在这一行末尾加上 ` --demo`。委托板会打开一组示例任务，停止时自动删除它们。

## 使用方法

- **快速添加：** 点击右下角的大按钮，或按 `N`。输入标题，按回车。输入框下方的图标可以选择类型、公会和截止时间；也可以直接输入 `#home` 或 `@11-02 18:00`。
- **完成任务：** 点击任务右上角的大对勾、屏幕顶部标题前的同一个对勾，或勾选它的最后一个完成条件。**勾掉一个步骤：** 点击它的状态标记；失败、放弃和给步骤设截止时间是旁边的小图标。
- **在原处编辑：** 铅笔图标可以编辑标题、简报、目标或完成条件。点击类型、公会或时间线上的任意日期即可修改。拖动步骤、完成条件和公会左侧的手柄可以调整顺序。
- **查找任务：** 使用顶部的搜索框。旁边的日历按钮可以只显示在两个日期之间到期的任务。
- **追踪一个任务**，让它的当前步骤一直显示在屏幕顶部；再给最多 **5 个任务加星标**，作为你的重点清单；这两个按钮就在任务标题前面。Markdown 和删除在每个任务的 `⋯` 菜单里；删除会把文件移到系统的回收站。
- **公会：** 把鼠标移到左侧栏的公会上，用铅笔图标重命名、设置图标或删除，用手柄移动；`+` 可以新建公会。
- 对任务的所有改动都可以用 `Ctrl+Z`（Mac 上是 `Cmd+Z`）撤销。
- **日历：** 可以切换为只看任务、任务加步骤，或包括已完成内容在内的全部。
- **点击等级徽章**，查看今天、本周、本月和今年完成了多少任务。
- **来自 AI：** 委托板可以为你生成一段提示词。把它和你的笔记一起粘贴到任意 AI 对话中，再把回答粘贴回来，委托板就会把它变成任务。委托板本身从不连接任何 AI。
- **你的任务** 是 `questboard.js` 旁边 `data` 文件夹里的 Markdown 文件。设置界面会显示这个文件夹、设置文件和你的启动命令。复制 `data` 文件夹即可备份。

高级用户的设置、Obsidian、手写任务文件、风格和语言：见 [ADVANCED.zh-CN.md](ADVANCED.zh-CN.md)。

## 卸载

1. **停止委托板**（如果它正在运行）。
2. **保留任务：** 如果想留下你的任务，先把 `data` 文件夹复制到别处。如果你把 `dataDir` 设成了别的文件夹，任务就在那里，删除委托板不会影响它们。
3. **删除委托板文件夹。** 委托板没有安装任何其他东西，删除这个文件夹就会连同设置一起移除它。

还有两样东西可能留下：

- **示例残留：** 没有正常停止的示例运行，可能会在系统临时文件夹里留下名为 `questboard-demo-…` 的文件夹。在 Windows 上，在文件资源管理器的地址栏输入 `%TEMP%` 打开它，然后删除这类文件夹。
- **Node.js** 是单独的程序。如果没有其他程序需要它，可以像卸载其他程序一样卸载它（Windows：**设置 → 应用 → 已安装的应用**）。
